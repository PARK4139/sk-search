- 원인: 미확인. ID 생성 변경은 Python 및 이슈 문서에 한정된다.
- 조치: 공통 fixture를 `cores/tests/fixtures/sample/tree/`로 추가하고 검색 테스트의 데이터 출처로 연결했다. ui_flow 단독 재실행 PASS 증거: ref/actual/logs/issue-id-ui-flow-retry.log.
- 결과: 미해결. 단독 재실행은 PASS이나 최초 실패 원인은 확인되지 않았다. 증거: ref/actual/logs/issue-id-ui-flow-retry.log.
- 재발 방지: 완료 이벤트와 재검색 결과의 세대·타이밍을 조사하고 재현 증거에 따라 수정한다.
