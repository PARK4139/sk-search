# title
화면 증거 캡처에 다른 창(사용자 화면 내용)이 포함됨

# pre-condition
- `cores/tests/scripts/run_capture.ps1` 초기 버전 (`Graphics.CopyFromScreen` 사용)
- 사용자가 다른 창을 사용 중 (skim-search 창 위에 겹침)

# steps
근거: rules/environment.md#증거-경로, AGENTS.md 9 / 발생: view/main-ui-components-missing/521ce549
1. `run_capture.ps1`로 skim-search 실행 및 캡처

# actual result
- 발생: `SetForegroundWindow`가 거부되어 사용자 창이 앞에 남음 → `CopyFromScreen`이 화면 영역을 그대로 복사하여 사용자 편집기 내용이 증거 파일에 저장됨.
- 같은 스크립트의 이전 결함도 함께 기록:
  - `Process.MainWindowHandle`이 debug build console 창을 가리킴 → 16x16 캡처, WM_CLOSE가 console로 가서 exit code `0xC000013A` (강제 종료)
  - `FindWindow($null, ...)`: PowerShell이 `$null`을 `""`로 전달 → 창 미발견
  - 시작 시 창 최소화 상태 → 160x28 캡처
- 조치 (2026-10-01):
  - 오염된 증거 파일 즉시 덮어씀
  - `FindWindow([NullString]::Value, "skim-search")`로 창 지정, `ShowWindow(SW_RESTORE)`
  - `PrintWindow(hwnd, PW_RENDERFULLCONTENT)`로 대상 창 내용만 캡처
  - 종료는 대상 창에 WM_CLOSE 전송
- 결과: PASS — 1168x807 skim-search 창만 캡처, exit code 0, 로그 `[app] exit ok`
  - 증거: `ref/actual/screenshot/frames/main-ui-components-missing_100.png`, `ref/actual/logs/skim-search.log`

# expected result
- 캡처 파일에 skim-search 창 내용만 포함된다. (다른 창이 겹쳐도)
- 캡처 후 앱이 정상 종료(exit code 0)된다.
- 검증 증거: 캡처 PNG, `ref/actual/logs/skim-search.log`
