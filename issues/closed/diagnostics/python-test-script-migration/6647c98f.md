- rg.exe / sk.exe and Rust build tools available

# steps
Source: user request (2026-10-01): add an issue to migrate the test scripts to Python
1. Check options, checks, exit codes and evidence output of `cores/tests/scripts/e2e_ui.ps1`, `e2e_detection.ps1`, `run_capture.ps1`, `bench_rg.ps1`, `bench_sk.ps1`.
