# title
PowerShell 테스트 스크립트를 Python으로 마이그레이션

# pre-condition
- Windows에서 기존 PowerShell 테스트 스크립트를 실행할 수 있는 환경
- Python 실행 환경과 필요한 패키지를 설치하고 버전 및 설치 명령을 문서화
- rg.exe / sk.exe 및 Rust 빌드 도구 사용 가능

# steps
근거: 사용자 요청 (2026-10-01): Python으로 test script 마이그레이션 이슈 추가
1. `cores/tests/scripts/e2e_ui.ps1`, `e2e_detection.ps1`, `run_capture.ps1`, `bench_rg.ps1`, `bench_sk.ps1`의 옵션, 검증 항목, 종료 코드 및 증거 출력을 확인한다.
2. 같은 검증 범위를 수행하는 Python 스크립트로 이전한다. Windows UI Automation, 화면 캡처, 앱 실행·종료, rg/sk 벤치마크를 포함한다.
3. `test.cmd` 및 기존 스크립트 호출·문서 참조를 Python 진입점으로 갱신한다.
4. 기존 스크립트와 Python 스크립트를 같은 환경·입력으로 실행해 검증 범위와 결과를 비교한다.
5. 이전 검증이 통과한 뒤 대체된 PowerShell 스크립트를 제거한다.
