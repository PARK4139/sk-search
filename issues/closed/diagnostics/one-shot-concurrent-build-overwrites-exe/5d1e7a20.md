# actual result
- 발생: CI 단계 `FAIL: release executable SHA/version mismatch` — `skim-search.exe --version` = `skim-search 0.1.0 unassigned` (기대 `0.1.1 <SHA>`). push 미호출, 원격 불변.

- 원인: pipeline 과 다른 작업이 같은 `CARGO_TARGET_DIR` 공유. 검사 자체는 의도대로 차단함.
- 조치: CI 가 `CARGO_TARGET_DIR=cores/target/one-shot` 사용, 기본 artifact 경로도 이동. `skim_tests.common` 의 EXE 경로가 `CARGO_TARGET_DIR` 를 따름 → e2e 가 pipeline 이 만든 exe 를 검사.
- 결과: PASS — `test_pipeline` 18/18. 실제 one-shot 재실행은 별도 기록.
- 추가 위험: commit 단계가 `git add --all` 이라 다른 작업자의 진행 중 파일이 push 범위에 섞일 수 있음 → 실행 전 작업 트리에 다른 작업자 변경이 없어야 함.
