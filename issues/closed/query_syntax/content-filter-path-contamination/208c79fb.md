# actual result
- `rg` 행을 `path<TAB>line<TAB>column<TAB>content`로 바꾸고 Skim에 `--delimiter TAB --nth 4..`를 전달.
- 실제 ripgrep/Skim 회귀 테스트에서 경로에 `login`이 포함되고 내용은 `logout();`인 행이 `logout !login` 결과에 남음. 입력 2행 중 1행 선택.
- 런타임 증거: `ref/actual/logs/skim-search.log` (`skim_input`, `content_filter`).
- 검증: `ref/actual/logs/cargo-build.log`, `cargo-test.log`, `cargo-clippy.log` 모두 성공.

# expected result
- Skim은 content field만 검색하고 path/line/column은 metadata로 보존한다. PASS.
- 실제 Skim에서 `logout !login` 결과에 경로의 `login`은 영향을 주지 않는다. PASS.
- 검증 증거: `ref/actual/logs/skim-search.log`, `ref/actual/logs/cargo-test.log`.
