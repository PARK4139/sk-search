# title
skim_input_from_rg가 줄 내용에 ':'가 있으면 줄을 malformed로 버림

# pre-condition
- `cores/app/src/query_syntax/mod.rs` `skim_input_from_rg` (다른 작업자 구현, content-filter-path-contamination에서 사용)

# steps
근거: handover §11 (rg 출력 path/line/column/text) / 발생: search_engine/auto-search-on-input 외 1차 묶음 (코드 검토)
1. rg 출력 `C:\a.ts:12:3:foo: bar` 를 입력

# actual result
- 발생: `rsplitn(4, ':')` 로 오른쪽부터 분리 → 내용의 ':' 에서 잘려 column/line 파싱 실패 → malformed 처리.
- 원인: 내용(text)이 마지막 필드인데 오른쪽부터 분리.
- 조치: 앱 검색 경로는 이 함수를 쓰지 않음 (engine은 rg `--null` + `ripgrep::parse_line`, sk에는 `id\tcontent`). 함수는 테스트에서만 사용.
- 결과: 미해결 — 함수 결함은 남아 있음(앱 동작 영향 없음). 해결 작업: 함수 제거 또는 `parse_line` 사용으로 교체 (다른 작업자 소유 파일이라 보류).

# expected result
- rg 출력 변환 함수는 내용에 ':'가 있어도 path/line/column/text를 정확히 분리한다.
