# title
`\` in Windows paths is rendered as `₩` (Malgun Gothic font)

# pre-condition
- `default-font-family: "Malgun Gothic"` in `cores/app/ui/main.slint`
- Search root box placeholder `D:\Projects\my-project`

# steps
Source: handover §5, §14, §24 (path display) / Origin: view/main-ui-components-missing/521ce549
1. Run skim-search.exe
2. Check the search root box

# actual result
- Occurred: shown as `D:₩Projects₩my-project`. Malgun Gothic draws the U+005C (`\`) glyph as `₩` (Korean code page convention).
- Cause: the UI default font was set to Malgun Gothic.
- Action (2026-10-01): changed to `default-font-family: "Segoe UI"`. Korean is shown through Slint font fallback.
- Result: PASS — `D:\Projects\my-project` shown correctly, Korean labels shown correctly.
  - Evidence: `ref/actual/screenshot/frames/main-ui-components-missing_100.png`

# expected result
- The path separator `\` is shown as is.
- Korean text is not garbled.
- Evidence: main window screenshot
