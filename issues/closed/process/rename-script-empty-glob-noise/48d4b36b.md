# title
폴더 영문화 스크립트 로그에 빈 폴더 glob이 UNMAPPED로 기록됨

# pre-condition
- `issues/working`, `issues/closed` 가 비어 있음
- `scratchpad/rename_en.sh` 가 `"$state"/*/` glob 사용

# steps
근거: AGENTS.md 9 (로그 검증) / 발생: 폴더 영문화 작업
1. `rename_en.sh` 실행

# actual result
- 발생: `unmapped=4` — `UNMAPPED_SUB working/*/*`, `UNMAPPED_FAM working/*` 등.
- 원인: bash에서 매칭 없는 glob이 문자열 그대로 남음 (nullglob 미설정).
- 조치: 로그 확인 후 실제 미매핑 0건으로 판정 (빈 폴더 artifact).
- 결과: PASS — 실제 이동 대상 68건 모두 매핑.
- 재발 방지: 폴더 순회 스크립트는 `shopt -s nullglob` 사용.

# expected result
- 로그의 UNMAPPED 항목은 실제 미매핑 폴더만 나타낸다.
