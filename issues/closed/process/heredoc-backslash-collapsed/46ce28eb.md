# pre-condition

# steps

- Occurred: the file got `"C:\a.ts"` → `error: unknown character escape: a`.
- Cause: the escaped backslash was collapsed to a single `\` while passing through the tool call.
- Action: used a raw string (`r"C:\a.ts"`) with the Edit tool.
- Result: PASS — compiles and tests pass.
- Prevention: code containing backslashes uses the Edit tool + raw strings.
