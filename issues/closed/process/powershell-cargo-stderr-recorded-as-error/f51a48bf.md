# title
PowerShell이 Cargo stderr를 NativeCommandError로 출력함

# pre-condition
- Windows PowerShell에서 Cargo build/test/clippy 실행

# steps
발생: query_syntax/content-filter-path-contamination/208c79fb
1. PowerShell에서 Cargo 출력을 파일로 리다이렉션
2. Rust 컴파일 메시지가 stderr로 출력되는 경우를 확인

# actual result
발생: Cargo 명령은 exit code 0이었지만 PowerShell 출력에 `NativeCommandError` 진단이 섞임.
원인: PowerShell의 native stderr 처리로 컴파일러 진행 메시지가 ErrorRecord로 표현됨.
조치: `cmd.exe /d /c` 리다이렉션으로 build/test/clippy 로그를 다시 생성하고 확인.
결과: PASS. 최종 로그에 `NativeCommandError` 또는 `error[` 항목이 없고 세 명령 모두 성공.
재발 방지: PowerShell에서 Rust 도구 로그를 수집할 때 native stderr 변환이 끼지 않는 리다이렉션 방식을 쓴다.

# expected result
Cargo 결과 로그에는 Cargo/Rust 출력을 원형에 가깝게 기록하고, 명령 종료 코드를 정확히 확인한다.
