# actual result
- Occurred: in 3 issues `D:\My Projects\...` → `D:My Projects...`, `\t` → tab, `C:\a.ts` → BEL character.
- Cause: `awk -v` interprets escape sequences in values. A later perl substitution again interpreted `\a` as BEL.
- Action: restored the 3 issues with the Edit tool and `\x5c` byte replacement; confirmed 0 control characters in all issues and rules.
- Result: PASS
- Prevention: pass bodies via file/stdin (`ENVIRON` or `getline`), never `-v`. Check for control characters after replacing.
